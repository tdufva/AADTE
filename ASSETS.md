# Collage assets

These are original, AI-generated magazine-style cutouts, not scans attributed to an existing publication. Created with the built-in image-generation tool with transparent backgrounds. The final delivery files are optimized WebP copies; the generated originals remain in the image-generation library. The print texture belongs to each fragment; no heavy page-wide effect is required.
